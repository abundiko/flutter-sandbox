# Gemini for AI

## Get a gemini API key

- visit `console.cloud.google.com` and create a new project
- visit `aistudio.google.com`
- select `get api key` (bottom left)
- press the `create api key +` button (top right)
- select the project created in step 1
- add the api key to a git hidden file in your app

## Initialize Gemini and Usage

- install with `flutter pub add flutter_gemini`
- refer to `https://pub.dev/packages/flutter_gemini#initialize-gemini` for usage docs
