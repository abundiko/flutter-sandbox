# Colors

to use colors in flutter these are the various ways:

- using the `Colors` class: `Colors.red`

- using the `Color` class: `Color(0xFF0000FF)`

- using Color.fromARGB(int alpha, int red, int green, int blue): `Color.fromARGB(255, 255, 0, 0)`

- using Color.fromRGBO(int red, int green, int blue, double opacity): `Color.fromRGBO(255, 0, 0, 1.0)`
